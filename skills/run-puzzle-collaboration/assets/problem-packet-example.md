# 题目包

## 题号/题名

示例-001／五位路径编码

## 最终需要

给出一个七字母英文单词；找到一种可验证解即可，不要求唯一性。

## 硬约束

每条路径恰有五步；1和2分别代表二进制位；顺序不可调整。

## 已确认正确的信息

前五组已经人工确认；后两组仍需核对原图。

## 材料清单

图1为完整题面；图2为最后两条路径的原图裁剪。

## 尚不确定的信息

第六组第三步可能是1或2。

## 允许的工具和操作

允许图像放大、逐位转录和程序枚举；不允许凭单词补齐未知路径。

## 网络与比赛界面边界

允许查询二进制编码和通用词典；禁止搜索题名、完整路径文本、原题或题解。比赛页面和所有点击操作均由用户完成，助手只使用用户提供的两张图片和后续返回结果。

## 证明与时间策略

先给已验证的部分解码；只有七组全部复核后才给最终答案。

## 答案格式

最终答案单独一行，随后列出七组二进制和逐字母对应。
